# 质检清单（交付前逐项过）

## 画面

```bash
bash $K/scripts/qc_sheet.sh <film>/out/片名.mp4 2     # 每 2 秒一帧，每张联系表 20 帧
```

**每一张联系表都要看完**，重点检查：

- [ ] 有没有超过 1 秒的空镜（镜头路过的地方只有地板）
- [ ] 字幕和画面里的标签、卡片有没有互相遮挡；任何时刻是否只有一条字幕
- [ ] 标签有没有跟错物体、超出画面、被积木挡住
- [ ] 镜头有没有飘走，导致主体出画或只露出一半
- [ ] 章节牌的编号和名字是否正确
- [ ] 数值和文字是否和脚本一致（编号、概率、计数）
- [ ] 片尾有没有写“示意”的说明
- [ ] 用 `render.ts still` 抽几张全尺寸帧，看细节：文字边缘是否清晰、阴影有没有断裂

## 声音

- [ ] `mix.py` 打印的三轨峰值：人声约 0.8，音乐约 0.3，音效不超过约 0.6
- [ ] 成片响度 -14 LUFS（±1），真峰值 ≤ -1.5 dBTP
- [ ] 音画同步：抽几个音效点，把那一帧和音效时间对一下
- [ ] **AI 自己听不到声音**：明确告诉用户需要亲耳听，尤其是人声和音乐的比例

## 封面

- [ ] 缩到 320 像素宽（手机列表的大小），标题还能读清
- [ ] 封面上的钩子文字，片子里确实讲到了

## 踩过的坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 混音跑了几个小时还没结束 | 用 `np.convolve` 对 1000 万个采样点做大窗口卷积，计算量约 10¹¹ | 用累加和算滑动平均（`mix.py` 里的 `movavg`） |
| 整条混音音量偏小 | 某个音效（比如“劈开”声）的峰值是其他音效的 3 倍，整条混音被它拉着一起缩小 | 把这个音效归一化，或调低它的 gain |
| 渲染速度掉到三分之一 | 和别的渲染任务抢 CPU | 错开时间跑，或者用 `nice` 降低其中一个的优先级 |
| 渲染链跑到一半断了 | 机器内存不足（OOM），或者会话退出 | 用 `setsid nohup` 把渲染进程挂到后台；`render_chunks.sh` 可以断点续跑 |
| 两条字幕叠在一起 | 一句话切成几屏时，时间点贴得太近 | 模板里的 `buildSubs()` 已经保证字幕时间单调递增、互不重叠，不要改坏它 |
| 成片颜色发灰或偏亮 | 色彩空间标错（BT.601 和 BT.709 混用） | 渲染脚本已经统一标成 bt709；如果要叠加外部素材，交付前和原素材逐张对比颜色 |
